## ColorUp 2 — Beta 1

Download **ColorUp-2.0.0-beta.1.apk** below. This is an experimental, debug-signed beta; the Android app reports version 2.0.0 (code 20).

### What's new

- Material You wallpaper colours with system, light and dark themes.
- Overview, Motion, Presets and Setup sections, searchable categories and focused slider editors.
- Independent profiles, curve graphs, motion previews, backups and presets.
- Drafts and imports survive screen recreation. Disable-all preserves your tuning.
- Correct LSPosed/Vector scope recommendations and device/runtime diagnostics.
- Spring endpoint, config validation and UI responsiveness fixes.

### Install

1. Export your existing ColorUp profiles before updating.
2. Install the APK and open ColorUp once.
3. Enable ColorUp in LSPosed/Vector and scope **System UI (`com.android.systemui`)**.
4. Reboot, enable a transition or load a preset, then **Save changes**.
5. Use **Setup → Copy diagnostic report** when reporting compatibility.

Different debug signing keys can prevent an in-place update. Keep a JSON backup before reinstalling, then restore it and re-enable the module. This beta does not establish a permanent production signing key.

### Engine coverage and device testing

**11 transitions have experimental hook candidates; 7 remain preview-only**, including app launch, home and recents. No physical Galaxy A35 hook validation has been completed. Intended firmware: SM-A356B, One UI 8.5 / Android 16, build BP4A.251205.006.A356BXXSCDZH1.

Installed candidates and recorded connections do not prove that Samsung invokes a hook. Use **Disable all hooks** to return to stock motion; if needed, disable ColorUp in your framework manager and reboot.
